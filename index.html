Real Analysis

The rigorous study of limits, continuity, differentiation, integration, and sequences and series of real numbers.

Metric Spaces

A metric space pairs a set with a distance function that formalizes notions like nearness and size.

Distance is never negative, and never infinite.

$$0 \textcolor{#7B4B8C}{\leq} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{<} \infty$$

Two points are at distance zero exactly when they are the same point.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} 0 \textcolor{#7B4B8C}{\iff} x \textcolor{#7B4B8C}{=} y$$

Distance doesn't depend on which point you measure from.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} \textcolor{#4078F2}{d}(y,x)$$

Going through a third point never shortens the direct route.

$$\textcolor{#4078F2}{d}(x,z) \textcolor{#7B4B8C}{\leq} \textcolor{#4078F2}{d}(x,y) + \textcolor{#4078F2}{d}(y,z)$$

The direct route x → z (dashed) is never longer than detouring through y.

Balls

An open ball collects every point within some fixed radius of a center point.

$$\textcolor{#C18401}{B}_r(x) \textcolor{#7B4B8C}{:=} \{y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \textcolor{#7B4B8C}{:} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{<} r\}$$

A closed ball additionally includes the points at distance exactly r.

$$\overline{\textcolor{#C18401}{B}}_r(x) \textcolor{#7B4B8C}{:=} \{y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \textcolor{#7B4B8C}{:} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{\leq} r\}$$

Convergence and Cauchy Sequences

A sequence converges when its terms get and stay arbitrarily close to a single limit point.

$$x_n \to x \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\geq} 1 \text{ s.t. } \textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x, x_n) \textcolor{#7B4B8C}{<} \varepsilon$$

Terms with index past N stay within ε of the limit x.

A sequence is Cauchy when its own terms eventually get arbitrarily close to each other, with no need to already know the limit.

$$\textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\geq} 1 \text{ s.t. } \textcolor{#7B4B8C}{\forall} m,n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x_m,x_n) \textcolor{#7B4B8C}{<} \varepsilon$$

Every convergent sequence is Cauchy, but the converse only holds once the space is complete.

Open and Closed Sets

An open set is one in which every point has some ball around it that still lies entirely inside the set.

$$\textcolor{#C18401}{U} \text{ open} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{U},\ \textcolor{#7B4B8C}{\exists}\, \varepsilon \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{B}_\varepsilon(x) \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{U}$$

A closed set contains the limit of every convergent sequence built from its own points.

$$\big(\textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\in} \mathbb{N},\ x_n \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}\big) \textcolor{#7B4B8C}{\wedge} x_n \to x\ \textcolor{#7B4B8C}{\implies}\ x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}$$

A set is closed exactly when its complement is open.

$$\textcolor{#C18401}{A} \text{ closed} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{M} \setminus \textcolor{#C18401}{A} \text{ open}$$

Open, not closed

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{<} 1\}$$

Closed, not open

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Closed and open

$$\textcolor{#C18401}{\mathbb{R}^2}$$

Closed and open

$$\textcolor{#C18401}{\varnothing}$$

Not closed, not open

$$\{x^2\!+\!y^2 \textcolor{#7B4B8C}{<} 1\} \cup \{x^2\!+\!y^2 \textcolor{#7B4B8C}{=} 1, y \textcolor{#7B4B8C}{\geq} 0\}$$

Not closed, not open

$$\{(x,y) : 0 \textcolor{#7B4B8C}{<} x^2+y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Dense Sets

A set is dense when every ball in the space contains at least one of its points, no matter how small — so its points can be found arbitrarily close to every point of the space.

$$\textcolor{#C18401}{A} \text{ dense in } \textcolor{#C18401}{M} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#C18401}{B}_\varepsilon(x) \textcolor{#7B4B8C}{\cap} \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\neq} \varnothing$$

No matter how small ε is, some point of A (dots) falls within ε of x — even though x itself need not be in A.

If a subset A of a metric space X is both closed and dense in X, then A = X.

Continuity

A function is continuous when small changes in input produce arbitrarily small changes in output.

$$\textcolor{#4078F2}{f} \text{ continuous at } x_0 \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\exists} \delta \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\forall} x\textcolor{#7B4B8C}{:}\,\textcolor{#4078F2}{d}(x_0,x) \textcolor{#7B4B8C}{<} \delta \textcolor{#7B4B8C}{\implies} \textcolor{#4078F2}{\rho}(\textcolor{#4078F2}{f}(x_0),\textcolor{#4078F2}{f}(x)) \textcolor{#7B4B8C}{<} \varepsilon$$

d measures distance in the input space, ρ measures distance in the output space — they can be different metrics on different spaces. In ℝ, both just mean |x − y|.

Keeping x within δ of x₀ (vertical band) keeps f(x) within ε of f(x₀) (horizontal band).

Boundedness

A set is bounded when the largest distance between any two of its points is finite.

$$\mathrm{diam}(\textcolor{#C18401}{A}) \textcolor{#7B4B8C}{:=} \textcolor{#7B4B8C}{\sup}_{x,y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}} \textcolor{#4078F2}{d}(x,y), \qquad \textcolor{#C18401}{A} \text{ bounded} \textcolor{#7B4B8C}{\iff} \mathrm{diam}(\textcolor{#C18401}{A}) \textcolor{#7B4B8C}{<} \infty$$

Equivalently, a set is bounded when it fits entirely inside some ball of finite radius.

$$\textcolor{#C18401}{A} \text{ bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\exists}\, x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists}\, r \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{B}_r(x)$$

Bounded

Total boundedness strengthens boundedness by requiring a set to be coverable by finitely many small balls.

$$\textcolor{#C18401}{A} \text{ totally bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#7B4B8C}{\bigcup}_{i=1}^{n} \textcolor{#C18401}{B}_\varepsilon(x_i) \text{ for some finite } x_1, \dots, x_n$$

Completeness

A complete space contains the limits of all its Cauchy sequences, leaving no "gaps" to converge into.

$$(\textcolor{#C18401}{M},\textcolor{#4078F2}{d}) \text{ complete} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \text{ Cauchy } (x_n) \text{ in } \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists}\, x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \text{ s.t. } x_n \textcolor{#7B4B8C}{\to} x$$

Within a complete ambient space, a subset is complete exactly when it is closed.

$$\textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{M},\ \textcolor{#C18401}{M} \text{ complete}\ \textcolor{#7B4B8C}{\implies}\ \big(\textcolor{#C18401}{A} \text{ complete} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{A} \text{ closed}\big)$$

Incomplete

$$\sqrt{2} \textcolor{#7B4B8C}{\notin} \textcolor{#C18401}{\mathbb{Q}}$$

Complete

$$\sqrt{2} \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{\mathbb{R}}$$

Compactness

A space is compact when it's both complete and totally bounded. In other words, no sequence escapes to a missing limit, and finitely many balls of any size still cover the whole space.

$$\textcolor{#C18401}{M} \text{ compact} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{M} \text{ complete} \textcolor{#7B4B8C}{\wedge} \textcolor{#C18401}{M} \text{ totally bounded}$$

Compact

$$\textcolor{#C18401}{[0,1]} \text{ complete} \textcolor{#7B4B8C}{\wedge} \text{ totally bounded}$$

Not compact

$$\textcolor{#C18401}{(0,1)} \text{ totally bounded}, \textcolor{#7B4B8C}{\neg} \text{ complete}$$

Bolzano–Weierstrass

The Bolzano–Weierstrass theorem gives an equivalent, sequence-based test for compactness: a space is compact exactly when every sequence inside it has a subsequence that converges to a point still inside the space.

$$\textcolor{#C18401}{M} \text{ compact} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} (x_n) \text{ in } \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists} \text{ subsequence } (x_{n_k}) \text{ s.t. } x_{n_k} \textcolor{#7B4B8C}{\to} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M}$$

Has a convergent subsequence

$$x_n \textcolor{#7B4B8C}{=} 1 \textcolor{#7B4B8C}{-} \tfrac{1}{n} \textcolor{#7B4B8C}{\to} 1 \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{[0,1]}$$

No subsequence converges inside

$$x_n \textcolor{#7B4B8C}{=} \tfrac{1}{n+1} \textcolor{#7B4B8C}{\to} 0 \textcolor{#7B4B8C}{\notin} \textcolor{#C18401}{(0,1)}$$

Sequences and Series of Functions

Pointwise convergence only asks each individual input to eventually settle, with no control over how fast that happens from one point to the next.

$$\forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\quad \textcolor{#4078F2}{f_n}(x) \to \textcolor{#4078F2}{f}(x) \text{ as } n \to \infty$$

The N here is allowed to depend on x — nothing requires one N to work for every point at once.

A spike pokes out of the tube at every n — it just relocates, so the function never fits inside all at once.

Uniform convergence requires the entire function, not just each point, to be well-approximated as n grows.

$$\textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly} \textcolor{#7B4B8C}{\iff} \sup_{x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M}} |\textcolor{#4078F2}{f_n}(x) - \textcolor{#4078F2}{f}(x)| \to 0 \text{ as } n \to \infty$$

Taking the supremum over x removes that freedom: the same N must work for every point at once.

Past some N, the whole function — not just one point — stays inside the tube.

A series of functions converges uniformly when its partial sums converge uniformly to the same limit function.

$$\textstyle\sum_{n=1}^{N} \textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly as } N \to \infty$$

The Weierstrass M-test gets uniform convergence for free: bound each term by a constant, and if those constants are summable, so is the series — uniformly.

$$\Big(\forall n,\ \forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ |\textcolor{#4078F2}{f_n}(x)| \le M_n\Big) \wedge \sum_{n=1}^{\infty} M_n < \infty\ \textcolor{#7B4B8C}{\implies}\ \sum_{n=1}^{\infty} \textcolor{#4078F2}{f_n} \text{ converges uniformly}$$

Optimization

The study of finding the best solution from a set of feasible options, often by maximizing or minimizing an objective function.

Linear Programming (LP) Formulation

Example: a factory picks liters of pink peppermint (x₁) and blueberry (x₂) ice cream to maximize profit under ingredient limits.

The factory wants to maximize profit from the liters it produces: $5 profit per liter of peppermint, $4 per liter of blueberry.

$$\max\quad 5\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2}$$

There's only so much milk on hand, so milk used across both flavors can't exceed the supply.

$$3\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2} \leq 24$$

Peppermint extract only goes into the peppermint flavor, and there's a limited supply of it.

$$\textcolor{#e64980}{x_1} \leq 6$$

Fresh blueberries are limited too, capping how much of that flavor can be made.

$$\textcolor{#3b6bd6}{x_2} \leq 5$$

You can't produce a negative number of liters.

$$\textcolor{#e64980}{x_1}, \textcolor{#3b6bd6}{x_2} \geq 0$$

The shaded region above is every feasible production plan. The best one sits at a corner — here, (x₁, x₂) = (6, 1.5), for a profit of 36.

Integer Linear Programming (ILP) Formulation

Example: a breakfast budget — pick green eggs (x₁) and slices of ham (x₂) to maximize protein without busting a €3 budget.

The goal is to maximize total protein from breakfast.

$$\max z = 7\textcolor{#2f9e44}{x_1} + 10\textcolor{#c2525c}{x_2}$$

Green eggs and ham each cost money, and the morning budget is fixed.

$$0.7\textcolor{#2f9e44}{x_1} + 0.9\textcolor{#c2525c}{x_2} \leq 3$$

You can only buy a whole number of eggs or ham slices — no fractions, which is what makes this an integer program.

$$\textcolor{#2f9e44}{x_1}, \textcolor{#c2525c}{x_2} \in \mathbb{Z}_{\geq 0}$$

The shaded region above is the continuous feasible area; the dots are the integer points inside it. The best integer point is (x₁, x₂) = (3, 1), for a value of 31 — not the same as rounding the LP relaxation's optimum of (0, 3.33), which scores 33.33.

Simplex

The simplex method never looks inside the feasible region — it starts at a corner and walks along the edges toward a better one.

Simplex starts at a feasible vertex — here, (0, 0) — then repeatedly pivots to an adjacent vertex along the boundary whenever that improves the objective: (0, 0) → (6, 0) → (6, 1.5). It stops once no neighboring vertex scores higher, landing on the optimum with a profit of 36.

The algorithm, as a repeatable procedure:

  1. Add a slack variable to each ≤ constraint, turning it into an equality.
  2. Set up the initial tableau with every slack basic and every structural variable at zero.
  3. Check optimality: if every coefficient in the objective row is already non-negative, stop — the current corner is optimal.
  4. Otherwise, choose the entering variable: the non-basic variable with the most negative objective-row coefficient.
  5. Choose the leaving variable with the minimum ratio test: among rows with a positive entry in the entering column, pick the one with the smallest RHS-to-coefficient ratio.
  6. Pivot — scale the chosen row so the entering variable's coefficient becomes 1, then clear that column from every other row, including the objective row.
  7. Repeat from step 3.

The same walk, numerically: the tableau starts with every slack basic, then pivots one variable in and one out per step.

Two-Phase Simplex

Add a minimum order to the same ice cream line: at least 2 liters total must be made, or it isn't worth running the machine.

$$\textcolor{#e64980}{x_1} + \textcolor{#3b6bd6}{x_2} \geq 2$$

Now the origin is infeasible, so simplex has nowhere obvious to start. Phase one ignores profit and just hunts for any feasible corner, using an artificial variable to patch the constraint; phase two then optimizes real profit from there.

The minimum-order line slices the corner nearest the origin off the feasible region, so (0, 0) is no longer a valid start. Phase one jumps straight to (2, 0) instead; phase two then walks (2, 0) → (6, 0) → (6, 1.5) to the same optimum, a profit of 36.

The procedure, building on ordinary simplex:

  1. For any constraint that isn't already ≤ with a non-negative right-hand side, add a surplus variable and an artificial variable to force an equality.
  2. Phase one: temporarily minimize the sum of the artificial variables, using the same entering/leaving/pivot rules as ordinary simplex, starting from the tableau where the artificials are basic.
  3. If phase one reaches zero, every artificial variable has left the basis (or sits at zero) — a feasible corner of the real region has been found. If it can't reach zero, the original problem is infeasible.
  4. Drop the artificial variables' columns, restore the real objective row, and recompute it against the current, now-feasible basis.
  5. Phase two: run ordinary simplex from there, pivoting on the real objective until every coefficient is non-negative.

Getting a Dual from a Primal

Every primal has a dual: a max problem's dual is a min problem, one dual variable per primal constraint and one dual constraint per primal variable.

Start from the ice cream factory's primal LP:

$$\max\quad 5\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2} \quad \text{s.t.} \quad 3\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2} \leq 24,\ \ \textcolor{#e64980}{x_1} \leq 6,\ \ \textcolor{#3b6bd6}{x_2} \leq 5$$

Building the dual, one piece at a time:

  1. Flip the objective direction — max becomes min.
  2. Give each primal constraint its own dual variable: y₁ for the milk constraint, y₂ for the peppermint constraint, y₃ for the blueberries constraint.
  3. Each primal constraint's right-hand side becomes that variable's objective coefficient: 24, 6, and 5 turn into min 24y₁ + 6y₂ + 5y₃.
  4. Give each primal variable its own dual constraint: one for x₁, one for x₂.
  5. Each primal variable's column of constraint coefficients becomes a dual constraint's row, and that variable's objective coefficient becomes the dual constraint's right-hand side. x₁'s column is (3, 1, 0) with objective coefficient 5, giving 3y₁ + y₂ ≥ 5. x₂'s column is (4, 0, 1) with objective coefficient 4, giving 4y₁ + y₃ ≥ 4.

Put together, that's the dual:

$$\min\ 24y_1 + 6y_2 + 5y_3 \quad \text{s.t.} \quad 3y_1 + y_2 \geq 5,\ \ 4y_1 + y_3 \geq 4,\ \ y_1, y_2, y_3 \geq 0$$

Rather than re-running simplex on it, read the solution off the primal's already-known optimal corner, (x₁, x₂) = (6, 1.5). Both x₁ and x₂ are positive, so both dual constraints must hold with equality; the blueberries constraint x₂ ≤ 5 isn't tight there (1.5 < 5), so y₃ must be 0.

$$4y_1 + y_3 = 4,\ y_3 = 0 \ \Longrightarrow\ y_1 = 1, \qquad 3y_1 + y_2 = 5 \ \Longrightarrow\ y_2 = 2$$

That gives y₁ = 1, y₂ = 2, y₃ = 0 — a dual objective of 24(1) + 6(2) + 5(0) = 24 + 12 = 36, exactly matching the primal's optimal profit.

Weak duality keeps the primal's rising values below the dual's falling ones at every step; strong duality is the special fact that, at the optimum, they meet exactly.

Gomory Cutting Planes

A Gomory cut adds a valid inequality — one that every integer point already satisfies — that slices a fractional corner off the LP relaxation, shrinking it toward the true integer hull.

Take the green-eggs-and-ham budget constraint. The Gomory split needs every variable in its row — including the slack — to be integer-valued at integer solutions, so scale away the decimals first.

$$0.7\textcolor{#2f9e44}{x_1} + 0.9\textcolor{#c2525c}{x_2} \leq 3 \quad\Longrightarrow\quad 7\textcolor{#2f9e44}{x_1} + 9\textcolor{#c2525c}{x_2} + s_1 = 30$$

At the LP optimum, ham (x₂) is the basic variable and it's fractional. Its simplex tableau row:

$$\textcolor{#c2525c}{x_2} + \tfrac{7}{9}\textcolor{#2f9e44}{x_1} + \tfrac{1}{9}s_1 = \tfrac{10}{3}$$

Gomory's cut keeps only the fractional part of each coefficient and of the right-hand side. Any integer solution still satisfies it, but the current fractional vertex can't — plugging in x₁ = s₁ = 0 gives 0 ≥ ⅓, which is false.

$$\tfrac{7}{9}\textcolor{#2f9e44}{x_1} + \tfrac{1}{9}s_1 \geq \tfrac{1}{3} \quad\Longrightarrow\quad 7\textcolor{#2f9e44}{x_1} + s_1 \geq 3$$

Substituting the slack back out in terms of the original variables collapses this to a single bound on ham, independent of eggs — exactly the cut drawn below.

$$7\textcolor{#2f9e44}{x_1} + (30 - 7\textcolor{#2f9e44}{x_1} - 9\textcolor{#c2525c}{x_2}) \geq 3 \quad\Longrightarrow\quad \textcolor{#c2525c}{x_2} \leq 3$$

The faint dashed outline above is the LP relaxation before any cuts. Since ham must be a whole number, x₂ ≤ 3.33 is really x₂ ≤ 3 — a valid cut that removes no integer point, but slices off the fractional corner and shrinks the relaxation's optimum from 33.33 down to 33, a step closer to the true integer optimum of 31.

Dijkstra's Algorithm

Dijkstra grows a shortest-path tree one node at a time, always settling the closest unvisited node next.

Complexity and NP-Completeness

P is every problem solvable quickly; NP is every problem whose solution can be checked quickly; NP-complete problems are the hardest problems in NP, each able to encode any other via a reduction.

If any single NP-complete problem (like SAT) turns out to be solvable quickly, a reduction lets every problem in NP ride along and be solved quickly too — that's exactly the open question "does P = NP?".

Statistics

The discipline of collecting, analyzing, interpreting, and presenting data to uncover patterns and inform decisions.

MLEs

Maximum likelihood picks whichever parameter value makes the observed data most probable.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ L(\theta) = \textcolor{#7B4B8C}{\arg\max_{\theta}} \prod_{i=1}^{n} f(x_i; \theta)$$

Products are awkward to differentiate, so in practice the log-likelihood is maximized instead — it has the same maximizer, with easier calculus.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ \ell(\theta), \quad \ell(\theta) = \sum_{i=1}^{n} \log f(x_i;\theta)$$

Bayesian inference

Bayesian inference treats the parameter itself as random, updating a prior belief into a posterior once data is observed.

$$\pi(\textcolor{#0b7285}{\theta} \mid x) \textcolor{#7B4B8C}{\propto} f(x \mid \textcolor{#0b7285}{\theta})\, \pi(\textcolor{#0b7285}{\theta})$$

In words: the posterior is proportional to the likelihood times the prior — the data reshapes belief, it doesn't replace it.

Method of moments

Method of moments estimates parameters by matching the sample's moments to the distribution's theoretical moments.

$$E[X^k] = \frac{1}{n}\sum_{i=1}^{n} X_i^k, \quad k = 1, 2, \dots$$

Solving these equations for the unknown parameters, one per moment used, gives the method-of-moments estimator.

$$\text{solve for } \textcolor{#0b7285}{\theta} \text{ using as many moments as there are parameters}$$

Hypothesis testing

A hypothesis test rejects the null hypothesis when the observed data would be too unlikely if the null were actually true.

$$\textcolor{#7B4B8C}{\text{reject } H_0} \textcolor{#7B4B8C}{\iff} \text{test statistic} \textcolor{#7B4B8C}{\in} \text{rejection region}$$

The rejection region is sized so that, if H₀ is actually true, the test wrongly rejects it only a small fraction of the time.

$$P(\textcolor{#7B4B8C}{\text{reject } H_0} \mid H_0 \text{ true}) = \textcolor{#c92a2a}{\alpha}$$

Likelihood ratio

The likelihood ratio compares how well the data is explained by the best-fitting restricted (null) model versus the best-fitting unrestricted model.

$$\Lambda = \frac{\sup_{\theta \in \Theta_0} L(\theta)}{\sup_{\theta \in \Theta} L(\theta)}$$

A ratio near 1 means restricting to H₀ barely hurt the fit; a ratio near 0 means the unrestricted model fits much better.

$$-2\log \Lambda \ \xrightarrow{d}\ \chi^2_{k}$$

Pivotal quantities

A pivotal quantity is built from both the data and the parameter, yet its own distribution never depends on the parameter's value.

$$\frac{\bar{X} - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{for every value of } \textcolor{#0b7285}{\mu}$$

Because that distribution is known regardless of the true parameter, a pivotal quantity can be inverted directly into a confidence interval.

Regression models

A regression model treats the response as a deterministic trend plus random noise, rather than an exact function of the predictors.

$$Y_i = \textcolor{#0b7285}{\beta_0} + \textcolor{#0b7285}{\beta_1} x_i + \varepsilon_i, \quad \varepsilon_i \textcolor{#7B4B8C}{\sim} N(0, \sigma^2)$$

Fitting the model means choosing the coefficients that make the residuals — the leftover noise — as small as possible.

$$(\hat{\textcolor{#0b7285}{\beta_0}}, \hat{\textcolor{#0b7285}{\beta_1}}) = \textcolor{#7B4B8C}{\arg\min_{\beta_0,\beta_1}} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_i)^2$$

Fisher information

Fisher information measures how sharply the log-likelihood curves at the true parameter — more curvature means the data pins the parameter down more precisely.

$$I(\textcolor{#0b7285}{\theta}) = -E\!\left[\frac{\partial^2}{\partial \textcolor{#0b7285}{\theta}^2} \log f(X; \textcolor{#0b7285}{\theta})\right]$$

It bounds how precise any unbiased estimator can possibly be, and approximates how precise the MLE actually is once the sample is large.

$$\text{Var}(\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}}) \approx \frac{1}{I(\textcolor{#0b7285}{\theta})}$$
