Real Analysis

The rigorous study of limits, continuity, differentiation, integration, and sequences and series of real numbers.

Metric Spaces

A metric space pairs a set with a distance function that formalizes notions like nearness and size.

Distance is never negative.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{\geq} 0$$

Two points are at distance zero exactly when they are the same point.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} 0 \textcolor{#7B4B8C}{\iff} x \textcolor{#7B4B8C}{=} y$$

Distance doesn't depend on which point you measure from.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} \textcolor{#4078F2}{d}(y,x)$$

Going through a third point never shortens the direct route.

$$\textcolor{#4078F2}{d}(x,z) \textcolor{#7B4B8C}{\leq} \textcolor{#4078F2}{d}(x,y) + \textcolor{#4078F2}{d}(y,z)$$

The direct route x → z (dashed) is never longer than detouring through y.

Open and Closed Sets

Open sets are built from balls that fit entirely inside them, while closed sets contain all of their limit points.

$$\textcolor{#C18401}{U} \text{ open} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{U},\ \textcolor{#7B4B8C}{\exists}\, \varepsilon \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{B}(x,\varepsilon) \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{U}$$

A set is closed exactly when its complement is open.

$$\textcolor{#C18401}{A} \text{ closed} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{X} \setminus \textcolor{#C18401}{A} \text{ open}$$

Equivalently, a closed set contains the limit of every convergent sequence built from its own points.

$$\big(\textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\in} \mathbb{N},\ x_n \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}\big) \textcolor{#7B4B8C}{\wedge} x_n \to x\ \textcolor{#7B4B8C}{\implies}\ x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}$$

Open, not closed

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{<} 1\}$$

Closed, not open

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Closed and open

$$\textcolor{#C18401}{\mathbb{R}^2}$$

Closed and open

$$\textcolor{#C18401}{\varnothing}$$

Not closed, not open

$$\{x^2\!+\!y^2 \textcolor{#7B4B8C}{<} 1\} \cup \{x^2\!+\!y^2 \textcolor{#7B4B8C}{=} 1, y \textcolor{#7B4B8C}{\geq} 0\}$$

Not closed, not open

$$\{(x,y) : 0 \textcolor{#7B4B8C}{<} x^2+y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Sequences and Convergence

A sequence converges when its terms get and stay arbitrarily close to a single limit point.

$$x_n \to x \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{\mathbb{N}} \text{ s.t. } \textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x_n, x) \textcolor{#7B4B8C}{<} \varepsilon$$

Terms with index past N stay within ε of the limit x.

Continuity

A function is continuous when small changes in input produce arbitrarily small changes in output.

$$\textcolor{#4078F2}{f} \text{ continuous at } x_0 \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists}\, \delta \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#4078F2}{d}(x,x_0) \textcolor{#7B4B8C}{<} \delta \textcolor{#7B4B8C}{\implies} \textcolor{#4078F2}{d}(\textcolor{#4078F2}{f}(x), \textcolor{#4078F2}{f}(x_0)) \textcolor{#7B4B8C}{<} \varepsilon$$

Keeping x within δ of x₀ (vertical band) keeps f(x) within ε of f(x₀) (horizontal band).

Boundedness

A set is bounded when it fits entirely inside some ball of finite radius.

$$\textcolor{#C18401}{A} \text{ bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\exists}\, x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X},\ \textcolor{#7B4B8C}{\exists}\, r \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{B}(x, r)$$

Total boundedness strengthens boundedness by requiring a set to be coverable by finitely many small balls.

$$\textcolor{#C18401}{A} \text{ totally bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#7B4B8C}{\bigcup}_{i=1}^{n} \textcolor{#C18401}{B}(x_i, \varepsilon) \text{ for some finite } x_1, \dots, x_n$$

Bounded

Totally bounded

Completeness and Compactness

A sequence is Cauchy when its own terms eventually get arbitrarily close to each other, with no need to already know the limit.

$$\textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{\mathbb{N}} \text{ s.t. } \textcolor{#7B4B8C}{\forall} m,n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x_m,x_n) \textcolor{#7B4B8C}{<} \varepsilon$$

A complete space contains the limits of all its Cauchy sequences, leaving no "gaps" to converge into.

$$(\textcolor{#C18401}{X},\textcolor{#4078F2}{d}) \text{ complete} \textcolor{#7B4B8C}{\iff} \text{every Cauchy sequence } (x_n) \text{ in } \textcolor{#C18401}{X} \text{ converges to some } x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X}$$

Missing its limit

$$\sqrt{2} \textcolor{#7B4B8C}{\notin} \textcolor{#C18401}{\mathbb{Q}}$$

Contains its limit

$$\sqrt{2} \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{\mathbb{R}}$$

A space is compact when every sequence inside it has a subsequence that converges to a point still inside the space.

$$\textcolor{#C18401}{X} \text{ compact} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} (x_n) \text{ in } \textcolor{#C18401}{X},\ \textcolor{#7B4B8C}{\exists} \text{ subsequence } (x_{n_k}) \text{ s.t. } x_{n_k} \textcolor{#7B4B8C}{\to} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X}$$

Compact

$$x_n \textcolor{#7B4B8C}{=} 1 \textcolor{#7B4B8C}{-} \tfrac{1}{n} \textcolor{#7B4B8C}{\to} 1 \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{[0,1]}$$

Not compact

$$x_n \textcolor{#7B4B8C}{=} \tfrac{1}{n+1} \textcolor{#7B4B8C}{\to} 0 \textcolor{#7B4B8C}{\notin} \textcolor{#C18401}{(0,1)}$$

Sequences and Series of Functions

Pointwise convergence only asks each individual input to eventually settle, with no control over how fast that happens from one point to the next.

$$\forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X},\quad \textcolor{#4078F2}{f_n}(x) \to \textcolor{#4078F2}{f}(x) \text{ as } n \to \infty$$

Uniform convergence requires the entire function, not just each point, to be well-approximated as n grows.

$$\textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly} \textcolor{#7B4B8C}{\iff} \sup_{x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X}} |\textcolor{#4078F2}{f_n}(x) - \textcolor{#4078F2}{f}(x)| \to 0 \text{ as } n \to \infty$$

Uniform

Eventually inside the ε-tube everywhere at once.

Pointwise only

A spike escapes the tube no matter how large n is.

A series of functions converges uniformly when its partial sums converge uniformly to the same limit function.

$$\textstyle\sum_{n=1}^{N} \textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly as } N \to \infty$$

The Weierstrass M-test gets uniform convergence for free: bound each term by a constant, and if those constants are summable, so is the series — uniformly.

$$\Big(\forall n,\ \forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{X},\ |\textcolor{#4078F2}{f_n}(x)| \le M_n\Big) \wedge \sum_{n=1}^{\infty} M_n < \infty \quad \textcolor{#7B4B8C}{\implies} \quad \sum_{n=1}^{\infty} \textcolor{#4078F2}{f_n} \text{ converges uniformly}$$

Optimization

The study of finding the best solution from a set of feasible options, often by maximizing or minimizing an objective function.

Linear Programming (LP) Formulation

Example: a factory picks liters of pink peppermint (x₁) and blueberry (x₂) ice cream to maximize profit under ingredient limits.

The factory wants to maximize profit from the liters it produces.

$$\max\quad 5\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2}$$

There's only so much milk on hand, so milk used across both flavors can't exceed the supply.

$$2\textcolor{#e64980}{x_1} + 4\textcolor{#3b6bd6}{x_2} \leq 24$$

Peppermint extract only goes into the peppermint flavor, and there's a limited supply of it.

$$\textcolor{#e64980}{x_1} \leq 6$$

Fresh blueberries are limited too, capping how much of that flavor can be made.

$$\textcolor{#3b6bd6}{x_2} \leq 5$$

You can't produce a negative number of liters.

$$\textcolor{#e64980}{x_1}, \textcolor{#3b6bd6}{x_2} \geq 0$$

Integer Linear Programming (ILP) Formulation

Example: a breakfast budget — pick green eggs (x₁) and slices of ham (x₂) to maximize protein without busting a €3 budget.

The goal is to maximize total protein from breakfast.

$$\max z = 7\textcolor{#2f9e44}{x_1} + 10\textcolor{#c2525c}{x_2}$$

Green eggs and ham each cost money, and the morning budget is fixed.

$$0.7\textcolor{#2f9e44}{x_1} + 0.9\textcolor{#c2525c}{x_2} \leq 3$$

You can only buy a whole number of eggs or ham slices — no fractions, which is what makes this an integer program.

$$\textcolor{#2f9e44}{x_1}, \textcolor{#c2525c}{x_2} \in \mathbb{Z}_{\geq 0}$$

Simplex

The simplex method never looks inside the feasible region — it starts at a corner and walks along the edges toward a better one.

The same walk, numerically: the tableau starts with every slack basic, then pivots one variable in and one out per step.

Two-Phase Simplex

Add a minimum order to the same ice cream line: at least 2 liters total must be made, or it isn't worth running the machine.

$$\textcolor{#e64980}{x_1} + \textcolor{#3b6bd6}{x_2} \geq 2$$

Now the origin is infeasible, so simplex has nowhere obvious to start. Phase one ignores profit and just hunts for any feasible corner, using an artificial variable to patch the constraint; phase two then optimizes real profit from there.

Getting a Dual from a Primal

Every primal has a dual: a max problem's dual is a min problem, one dual variable per primal constraint and one dual constraint per primal variable.

Take the ice cream factory's LP: swap max for min, turn each primal constraint's right-hand side (24, 6, 5) into a dual objective coefficient, and each primal objective coefficient (5, 4) into a dual constraint's right-hand side.

$$\min\ 24y_1 + 6y_2 + 5y_3 \quad \text{s.t.} \quad 2y_1 + y_2 \geq 5,\ \ 4y_1 + y_3 \geq 4,\ \ y_1, y_2, y_3 \geq 0$$

Solving it lands on y₁ = 1, y₂ = 3, y₃ = 0 — a dual objective of 24(1) + 6(3) + 5(0) = 42, exactly matching the primal's optimal profit.

Weak duality keeps the primal's rising values below the dual's falling ones at every step; strong duality is the special fact that, at the optimum, they meet exactly.

Dijkstra's Algorithm

Dijkstra grows a shortest-path tree one node at a time, always settling the closest unvisited node next.

Gomory Cutting Planes

A Gomory cut adds a valid inequality — one that every integer point already satisfies — that slices a fractional corner off the LP relaxation, shrinking it toward the true integer hull.

Complexity and NP-Completeness

P is every problem solvable quickly; NP is every problem whose solution can be checked quickly; NP-complete problems are the hardest problems in NP, each able to encode any other via a reduction.

If any single NP-complete problem (like SAT) turns out to be solvable quickly, a reduction lets every problem in NP ride along and be solved quickly too — that's exactly the open question "does P = NP?".

Statistics

The discipline of collecting, analyzing, interpreting, and presenting data to uncover patterns and inform decisions.

Regression models

A regression model treats the response as a deterministic trend plus random noise, rather than an exact function of the predictors.

$$Y_i = \textcolor{#0b7285}{\beta_0} + \textcolor{#0b7285}{\beta_1} x_i + \varepsilon_i, \quad \varepsilon_i \textcolor{#7B4B8C}{\sim} N(0, \sigma^2)$$

Fitting the model means choosing the coefficients that make the residuals — the leftover noise — as small as possible.

$$(\hat{\textcolor{#0b7285}{\beta_0}}, \hat{\textcolor{#0b7285}{\beta_1}}) = \textcolor{#7B4B8C}{\arg\min_{\beta_0,\beta_1}} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_i)^2$$

MLEs

Maximum likelihood picks whichever parameter value makes the observed data most probable.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ L(\theta) = \textcolor{#7B4B8C}{\arg\max_{\theta}} \prod_{i=1}^{n} f(x_i; \theta)$$

Products are awkward to differentiate, so in practice the log-likelihood is maximized instead — it has the same maximizer, with easier calculus.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ \ell(\theta), \quad \ell(\theta) = \sum_{i=1}^{n} \log f(x_i;\theta)$$

Bayesian inference

Bayesian inference treats the parameter itself as random, updating a prior belief into a posterior once data is observed.

$$\pi(\textcolor{#0b7285}{\theta} \mid x) \textcolor{#7B4B8C}{\propto} f(x \mid \textcolor{#0b7285}{\theta})\, \pi(\textcolor{#0b7285}{\theta})$$

In words: the posterior is proportional to the likelihood times the prior — the data reshapes belief, it doesn't replace it.

Method of moments

Method of moments estimates parameters by matching the sample's moments to the distribution's theoretical moments.

$$E[X^k] = \frac{1}{n}\sum_{i=1}^{n} X_i^k, \quad k = 1, 2, \dots$$

Solving these equations for the unknown parameters, one per moment used, gives the method-of-moments estimator.

$$\text{solve for } \textcolor{#0b7285}{\theta} \text{ using as many moments as there are parameters}$$

Hypothesis testing

A hypothesis test rejects the null hypothesis when the observed data would be too unlikely if the null were actually true.

$$\textcolor{#7B4B8C}{\text{reject } H_0} \textcolor{#7B4B8C}{\iff} \text{test statistic} \textcolor{#7B4B8C}{\in} \text{rejection region}$$

The rejection region is sized so that, if H₀ is actually true, the test wrongly rejects it only a small fraction of the time.

$$P(\textcolor{#7B4B8C}{\text{reject } H_0} \mid H_0 \text{ true}) = \textcolor{#c92a2a}{\alpha}$$

Likelihood ratio

The likelihood ratio compares how well the data is explained by the best-fitting restricted (null) model versus the best-fitting unrestricted model.

$$\Lambda = \frac{\sup_{\theta \in \Theta_0} L(\theta)}{\sup_{\theta \in \Theta} L(\theta)}$$

A ratio near 1 means restricting to H₀ barely hurt the fit; a ratio near 0 means the unrestricted model fits much better.

$$-2\log \Lambda \ \xrightarrow{d}\ \chi^2_{k}$$

Pivotal quantities

A pivotal quantity is built from both the data and the parameter, yet its own distribution never depends on the parameter's value.

$$\frac{\bar{X} - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{for every value of } \textcolor{#0b7285}{\mu}$$

Because that distribution is known regardless of the true parameter, a pivotal quantity can be inverted directly into a confidence interval.

Fisher information

Fisher information measures how sharply the log-likelihood curves at the true parameter — more curvature means the data pins the parameter down more precisely.

$$I(\textcolor{#0b7285}{\theta}) = -E\!\left[\frac{\partial^2}{\partial \textcolor{#0b7285}{\theta}^2} \log f(X; \textcolor{#0b7285}{\theta})\right]$$

It bounds how precise any unbiased estimator can possibly be, and approximates how precise the MLE actually is once the sample is large.

$$\text{Var}(\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}}) \approx \frac{1}{I(\textcolor{#0b7285}{\theta})}$$
