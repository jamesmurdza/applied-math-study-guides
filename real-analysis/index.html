Real Analysis

The rigorous study of limits, continuity, differentiation, integration, and sequences and series of real numbers.

Metric Spaces

A metric space pairs a set M with a distance function d that formalizes notions like nearness and size.

Distance is never negative, and never infinite.

$$0 \textcolor{#7B4B8C}{\leq} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{<} \infty$$

Two points are at distance zero exactly when they are the same point.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} 0 \textcolor{#7B4B8C}{\iff} x \textcolor{#7B4B8C}{=} y$$

Distance doesn't depend on which point you measure from.

$$\textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{=} \textcolor{#4078F2}{d}(y,x)$$

Going through a third point never shortens the direct route.

$$\textcolor{#4078F2}{d}(x,z) \textcolor{#7B4B8C}{\leq} \textcolor{#4078F2}{d}(x,y) + \textcolor{#4078F2}{d}(y,z)$$

The direct route x → z (dashed) is never longer than detouring through y.

Convergence and Cauchy Sequences

A sequence converges when its terms get and stay arbitrarily close to a single limit point.

$$x_n \to x \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\geq} 1 \text{ s.t. } \textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x, x_n) \textcolor{#7B4B8C}{<} \varepsilon$$

N depends on ε — smaller windows generally need larger N before the terms stay inside.

Terms with index past N stay within ε of the limit x.

A sequence is Cauchy when its own terms eventually get arbitrarily close to each other, with no need to already know the limit.

$$\textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#7B4B8C}{\exists} N \textcolor{#7B4B8C}{\geq} 1 \text{ s.t. } \textcolor{#7B4B8C}{\forall} m,n \textcolor{#7B4B8C}{\geq} N,\ \textcolor{#4078F2}{d}(x_m,x_n) \textcolor{#7B4B8C}{<} \varepsilon$$

Every convergent sequence is Cauchy, but the converse only holds once the space is complete.

Balls

An open ball collects every point within some fixed radius of a center point.

$$\textcolor{#C18401}{B}_r(x) \textcolor{#7B4B8C}{:=} \{y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \textcolor{#7B4B8C}{:} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{<} r\}$$

A closed ball additionally includes the points at distance exactly r.

$$\overline{\textcolor{#C18401}{B}}_r(x) \textcolor{#7B4B8C}{:=} \{y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \textcolor{#7B4B8C}{:} \textcolor{#4078F2}{d}(x,y) \textcolor{#7B4B8C}{\leq} r\}$$

Open and Closed Sets

A subset A ⊆ M is a smaller set living inside the ambient space M, still measured by the same d.

An open subset is one in which every point has some ball around it that still lies entirely inside the set.

$$\textcolor{#C18401}{U} \text{ open} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{U},\ \textcolor{#7B4B8C}{\exists}\, \varepsilon \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{B}_\varepsilon(x) \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{U}$$

A closed subset contains the limit of every convergent sequence built from its own points.

$$\big(\textcolor{#7B4B8C}{\forall} n \textcolor{#7B4B8C}{\in} \mathbb{N},\ x_n \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}\big) \textcolor{#7B4B8C}{\wedge} x_n \to x\ \textcolor{#7B4B8C}{\implies}\ x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}$$

A subset is closed exactly when its complement is open.

$$\textcolor{#C18401}{A} \text{ closed} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{M} \setminus \textcolor{#C18401}{A} \text{ open}$$

Openness and closedness depend on the ambient space and the metric d.

Open, not closed

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{<} 1\}$$

Closed, not open

$$\{(x,y) : x^2 + y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Closed and open

$$\textcolor{#C18401}{\mathbb{R}^2}$$

Closed and open

$$\textcolor{#C18401}{\varnothing}$$

Not closed, not open

$$\{x^2\!+\!y^2 \textcolor{#7B4B8C}{<} 1\} \cup \{x^2\!+\!y^2 \textcolor{#7B4B8C}{=} 1, y \textcolor{#7B4B8C}{\geq} 0\}$$

Not closed, not open

$$\{(x,y) : 0 \textcolor{#7B4B8C}{<} x^2+y^2 \textcolor{#7B4B8C}{\leq} 1\}$$

Dense Sets

A subset is dense when every ball in the space contains at least one of its points, no matter how small — so its points can be found arbitrarily close to every point of the space.

$$\textcolor{#C18401}{A} \text{ dense in } \textcolor{#C18401}{M} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#C18401}{B}_\varepsilon(x) \textcolor{#7B4B8C}{\cap} \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\neq} \varnothing$$

x ranges over the whole space, not just A — even points outside A must have A's points arbitrarily close by.

The dots are points of A; every ε-window around x ∋ M still catches one.

If a subset A of a metric space M is both closed and dense in M, then A = M.

Continuity

A function is continuous when small changes in input produce arbitrarily small changes in output.

$$\textcolor{#4078F2}{f} \text{ continuous at } x_0 \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\exists} \delta \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\forall} x\textcolor{#7B4B8C}{:}\,\textcolor{#4078F2}{d}(x_0,x) \textcolor{#7B4B8C}{<} \delta \textcolor{#7B4B8C}{\implies} \textcolor{#4078F2}{\rho}(\textcolor{#4078F2}{f}(x_0),\textcolor{#4078F2}{f}(x)) \textcolor{#7B4B8C}{<} \varepsilon$$

d measures distance in the input space, ρ measures distance in the output space — they can be different metrics on different spaces. In ℝ, both just mean |x − y|.

Keeping x within δ of x₀ (vertical band) keeps f(x) within ε of f(x₀) (horizontal band).

Continuity only promises a δ for each x₀ separately — it can shrink as x₀ varies. A function is uniformly continuous when one δ works for every point at once.

$$\textcolor{#4078F2}{f} \text{ uniformly continuous} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\exists} \delta \textcolor{#7B4B8C}{>} 0\,\textcolor{#7B4B8C}{\forall} x,x_0\textcolor{#7B4B8C}{:}\,\textcolor{#4078F2}{d}(x_0,x) \textcolor{#7B4B8C}{<} \delta \textcolor{#7B4B8C}{\implies} \textcolor{#4078F2}{\rho}(\textcolor{#4078F2}{f}(x_0),\textcolor{#4078F2}{f}(x)) \textcolor{#7B4B8C}{<} \varepsilon$$

The only change from continuity above is where δ is chosen: after x₀ (∀x₀∃δ) versus before it (∃δ∀x₀). x² is continuous but not uniformly continuous on ℝ — as x₀ grows, the same ε forces δ smaller. A Lipschitz function is a stronger, concrete case: distances in the output are capped by a constant multiple of distances in the input, which hands δ = ε/L directly, independent of x₀.

$$\textcolor{#4078F2}{f} \text{ Lipschitz} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\exists}\, L \textcolor{#7B4B8C}{>} 0\ \textcolor{#7B4B8C}{\forall} x,x_0\textcolor{#7B4B8C}{:}\ \textcolor{#4078F2}{\rho}(\textcolor{#4078F2}{f}(x_0),\textcolor{#4078F2}{f}(x)) \textcolor{#7B4B8C}{\le} L \cdot \textcolor{#4078F2}{d}(x_0,x)$$

Every Lipschitz function is uniformly continuous, but not conversely — √x on [0,∞) is uniformly continuous without being Lipschitz, since its slope near 0 is unbounded.

Boundedness

A subset is bounded when the largest distance between any two of its points is finite.

$$\mathrm{diam}(\textcolor{#C18401}{A}) \textcolor{#7B4B8C}{:=} \textcolor{#7B4B8C}{\sup}_{x,y \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{A}} \textcolor{#4078F2}{d}(x,y), \qquad \textcolor{#C18401}{A} \text{ bounded} \textcolor{#7B4B8C}{\iff} \mathrm{diam}(\textcolor{#C18401}{A}) \textcolor{#7B4B8C}{<} \infty$$

Equivalently, a subset is bounded when it fits entirely inside some ball of finite radius.

$$\textcolor{#C18401}{A} \text{ bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\exists}\, x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists}\, r \textcolor{#7B4B8C}{>} 0 \text{ s.t. } \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{B}_r(x)$$

x can be any point of the space — the ball's center doesn't need to lie in A.

One ball of radius r contains all of A.

Total boundedness strengthens boundedness by requiring a subset to be coverable by finitely many small balls.

$$\textcolor{#C18401}{A} \text{ totally bounded} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \varepsilon \textcolor{#7B4B8C}{>} 0,\ \textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#7B4B8C}{\bigcup}_{i=1}^{n} \textcolor{#C18401}{B}_\varepsilon(x_i) \text{ for some finite } x_1, \dots, x_n$$

The number of balls can grow as ε shrinks — but it's always finite.

Four balls of radius ε already cover all of A.

Completeness

A complete space contains the limits of all its Cauchy sequences, leaving no "gaps" to converge into.

$$(\textcolor{#C18401}{M},\textcolor{#4078F2}{d}) \text{ complete} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} \text{ Cauchy } (x_n) \text{ in } \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists}\, x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M} \text{ s.t. } x_n \textcolor{#7B4B8C}{\to} x$$

Within a complete ambient space, a subset is complete exactly when it is closed.

$$\textcolor{#C18401}{A} \textcolor{#7B4B8C}{\subseteq} \textcolor{#C18401}{M},\ \textcolor{#C18401}{M} \text{ complete}\ \textcolor{#7B4B8C}{\implies}\ \big(\textcolor{#C18401}{A} \text{ complete} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{A} \text{ closed}\big)$$

Compactness

A space is compact when it's both complete and totally bounded. In other words, no sequence escapes to a missing limit, and finitely many balls of any size still cover the whole space.

$$\textcolor{#C18401}{M} \text{ compact} \textcolor{#7B4B8C}{\iff} \textcolor{#C18401}{M} \text{ complete} \textcolor{#7B4B8C}{\wedge} \textcolor{#C18401}{M} \text{ totally bounded}$$

Bolzano–Weierstrass

The Bolzano–Weierstrass theorem gives an equivalent, sequence-based test for compactness: a space is compact exactly when every sequence inside it has a subsequence that converges to a point still inside the space.

$$\textcolor{#C18401}{M} \text{ compact} \textcolor{#7B4B8C}{\iff} \textcolor{#7B4B8C}{\forall} (x_n) \text{ in } \textcolor{#C18401}{M},\ \textcolor{#7B4B8C}{\exists} \text{ subsequence } (x_{n_k}) \text{ s.t. } x_{n_k} \textcolor{#7B4B8C}{\to} x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M}$$

Sequences and Series of Functions

Pointwise convergence only asks each individual input to eventually settle, with no control over how fast that happens from one point to the next.

$$\forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\quad \textcolor{#4078F2}{f_n}(x) \to \textcolor{#4078F2}{f}(x) \text{ as } n \to \infty$$

N depends on x here — each point is allowed to settle at its own pace.

Each fₙ still has a spike poking outside the ε tube, just relocated.

Uniform convergence requires the entire function, not just each point, to be well-approximated as n grows.

$$\textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly} \textcolor{#7B4B8C}{\iff} \sup_{x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M}} |\textcolor{#4078F2}{f_n}(x) - \textcolor{#4078F2}{f}(x)| \to 0 \text{ as } n \to \infty$$

N no longer depends on x — every point must settle at the same pace.

f₃ already fits inside the ε tube everywhere; f₁ and f₂ still don't.

A series of functions converges uniformly when its partial sums converge uniformly to the same limit function.

$$\textstyle\sum_{n=1}^{N} \textcolor{#4078F2}{f_n} \to \textcolor{#4078F2}{f} \text{ uniformly as } N \to \infty$$

The Weierstrass M-test gets uniform convergence for free: bound each term by a constant, and if those constants are summable, so is the series — uniformly.

$$\Big(\forall n,\ \forall x \textcolor{#7B4B8C}{\in} \textcolor{#C18401}{M},\ |\textcolor{#4078F2}{f_n}(x)| \le M_n\Big) \wedge \sum_{n=1}^{\infty} M_n < \infty\ \textcolor{#7B4B8C}{\implies}\ \sum_{n=1}^{\infty} \textcolor{#4078F2}{f_n} \text{ converges uniformly}$$
