Real Analysis Optimization Statistics

Statistics

The discipline of collecting, analyzing, interpreting, and presenting data to uncover patterns and inform decisions.

MLEs

Maximum likelihood picks whichever parameter value makes the observed data most probable.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ L(\theta) = \textcolor{#7B4B8C}{\arg\max_{\theta}} \prod_{i=1}^{n} f(x_i; \theta)$$

Products are awkward to differentiate, so in practice the log-likelihood is maximized instead — it has the same maximizer, with easier calculus.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ \ell(\theta), \quad \ell(\theta) = \sum_{i=1}^{n} \log f(x_i;\theta)$$

Bayesian inference

Bayesian inference treats the parameter itself as random, updating a prior belief into a posterior once data is observed.

$$\pi(\textcolor{#0b7285}{\theta} \mid x) \textcolor{#7B4B8C}{\propto} f(x \mid \textcolor{#0b7285}{\theta})\, \pi(\textcolor{#0b7285}{\theta})$$

In words: the posterior is proportional to the likelihood times the prior — the data reshapes belief, it doesn't replace it.

Method of moments

Method of moments estimates parameters by matching the sample's moments to the distribution's theoretical moments.

$$E[X^k] = \frac{1}{n}\sum_{i=1}^{n} X_i^k, \quad k = 1, 2, \dots$$

Solving these equations for the unknown parameters, one per moment used, gives the method-of-moments estimator.

$$\text{solve for } \textcolor{#0b7285}{\theta} \text{ using as many moments as there are parameters}$$

Bias and Mean Squared Error

An estimator's bias is the gap between its expected value and the true parameter; an unbiased estimator gets the right answer on average, even though any single sample's estimate can still land off target.

$$\text{Bias}(\hat{\textcolor{#0b7285}{\theta}}) = E[\hat{\textcolor{#0b7285}{\theta}}] - \textcolor{#0b7285}{\theta}$$

Low bias alone isn't the whole story — an estimator can be perfectly unbiased yet swing wildly from sample to sample. Mean squared error folds both effects into one number, and splits cleanly into variance plus bias squared.

$$\text{MSE}(\hat{\textcolor{#0b7285}{\theta}}) = E[(\hat{\textcolor{#0b7285}{\theta}}-\textcolor{#0b7285}{\theta})^2] = \text{Var}(\hat{\textcolor{#0b7285}{\theta}}) + \text{Bias}(\hat{\textcolor{#0b7285}{\theta}})^2$$

Revisiting the 7-heads-in-10-flips example from MLEs and Bayesian inference above: if the true p were 0.7, the MLE p̂ = X/n is unbiased — Bias(p̂) = 0 — with Var(p̂) = p(1−p)/n = 0.021, so MSE(p̂) = 0.021 too. The Bayesian posterior mean (X+2)/(n+4) is biased toward the Beta(2,2) prior's center, Bias ≈ −0.057, but its variance is smaller, Var ≈ 0.011, so MSE ≈ 0.014 — the biased estimator actually wins on MSE here, trading a little bias for a bigger cut in variance.

Hypothesis testing

A hypothesis test rejects the null hypothesis when the observed data would be too unlikely if the null were actually true.

$$\textcolor{#7B4B8C}{\text{reject } H_0} \textcolor{#7B4B8C}{\iff} \text{test statistic} \textcolor{#7B4B8C}{\in} \text{rejection region}$$

The rejection region is sized so that, if H₀ is actually true, the test wrongly rejects it only a small fraction of the time: below, the shaded tail holds exactly α = 0.05 of the area under the null distribution, cut off at the critical value z* = 1.645. The observed statistic falls at z = 2.1 — past z*, inside the rejection region — so H₀ is rejected.

$$P(\textcolor{#7B4B8C}{\text{reject } H_0} \mid H_0 \text{ true}) = \textcolor{#c92a2a}{\alpha}$$

Student's t-tests

The general hypothesis-testing machinery above specializes into a concrete, named test whenever the data is (approximately) normal and the population variance is unknown — estimating that variance from the sample is exactly what turns a z-statistic into a t-statistic. It's the same pivotal quantity as in Pivotal quantities below, used here as a test statistic instead of being inverted into an interval.

$$T = \frac{\bar X - \textcolor{#0b7285}{\mu_0}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{under } H_0: \mu = \textcolor{#0b7285}{\mu_0}$$

The same statistic form covers three cases, distinguished only by what's compared and how the standard error is built: a one-sample test checks a single mean against μ₀ (above); a paired test takes differences Dᵢ = Xᵢ − Yᵢ within each pair and reduces to the one-sample test on D̄; a two-sample test compares X̄ − Ȳ directly, with the standard error combining both samples' variability.

$$T = \frac{\bar X - \bar Y}{S_p\sqrt{\tfrac{1}{n_1}+\tfrac{1}{n_2}}} \textcolor{#7B4B8C}{\sim} t_{n_1+n_2-2}$$

Degrees of freedom drop by one for every mean already estimated from the data: n−1 for the one-sample and paired cases, n₁+n₂−2 once two independent sample means and a pooled variance are involved.

Likelihood ratio

The likelihood ratio compares how well the data is explained by the best-fitting restricted (null) model versus the best-fitting unrestricted model.

$$\Lambda = \frac{\sup_{\theta \in \Theta_0} L(\theta)}{\sup_{\theta \in \Theta} L(\theta)}$$

A ratio near 1 means restricting to H₀ barely hurt the fit; a ratio near 0 means the unrestricted model fits much better.

$$-2\log \Lambda \ \xrightarrow{d}\ \chi^2_{k}$$

Pivotal quantities

A pivotal quantity is built from both the data and the parameter, yet its own distribution never depends on the parameter's value.

$$\frac{\bar{X} - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{for every value of } \textcolor{#0b7285}{\mu}$$

Because that distribution is known regardless of the true parameter, a pivotal quantity can be inverted directly into a confidence interval.

Confidence Intervals

Inverting a pivotal quantity means asking which parameter values would make the observed pivot land in its typical range — that set of values is the confidence interval. Because the pivot's own distribution never depends on the parameter, the interval's coverage probability is exact, not approximate.

$$P\!\left(-t^*_{n-1} \le \frac{\bar X - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \le t^*_{n-1}\right) = 1-\textcolor{#c92a2a}{\alpha} \quad\Longrightarrow\quad \textcolor{#0b7285}{\mu} \in \bar X \pm t^*_{n-1}\frac{S}{\sqrt{n}}$$

When no exact pivot exists — the statistic's distribution still depends somewhat on the parameter — a near-pivot built from a large-sample, asymptotically normal approximation serves the same role, at the cost of that coverage probability holding only approximately rather than exactly.

Regression models

A regression model treats the response as a deterministic trend plus random noise, rather than an exact function of the predictors.

$$Y_i = \textcolor{#0b7285}{\beta_0} + \textcolor{#0b7285}{\beta_1} x_i + \varepsilon_i, \quad \varepsilon_i \textcolor{#7B4B8C}{\sim} N(0, \sigma^2)$$

Fitting the model means choosing the coefficients that make the residuals — the leftover noise — as small as possible.

$$(\hat{\textcolor{#0b7285}{\beta_0}}, \hat{\textcolor{#0b7285}{\beta_1}}) = \textcolor{#7B4B8C}{\arg\min_{\beta_0,\beta_1}} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_i)^2$$

Regression Diagnostics

Fitting a regression model doesn't guarantee a good fit — the model above assumed a linear trend, constant-variance errors, and normally distributed noise, and residual plots are how those assumptions get checked after the fact, since the true errors are never observed, only their estimates, the residuals.

$$e_i = y_i - \hat y_i = y_i - (\hat{\textcolor{#0b7285}{\beta_0}} + \hat{\textcolor{#0b7285}{\beta_1}} x_i)$$

Plotting residuals against the fitted values should show patternless, constant-width scatter around zero if the assumptions hold; a pattern — like the fan shape below, where the spread visibly grows with the fitted value — signals heteroscedasticity, a violation of the constant-variance assumption.

A separate summary number, R², reports the proportion of the total variance in y explained by the fitted line rather than left over in the residuals.

$$R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}$$

Fisher information

Fisher information measures how sharply the log-likelihood curves at the true parameter — more curvature means the data pins the parameter down more precisely.

$$I(\textcolor{#0b7285}{\theta}) = -E\!\left[\frac{\partial^2}{\partial \textcolor{#0b7285}{\theta}^2} \log f(X; \textcolor{#0b7285}{\theta})\right]$$

It bounds how precise any unbiased estimator can possibly be, and approximates how precise the MLE actually is once the sample is large.

$$\text{Var}(\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}}) \approx \frac{1}{I(\textcolor{#0b7285}{\theta})}$$
