Statistics

The discipline of collecting, analyzing, interpreting, and presenting data to uncover patterns and inform decisions.

Method of Moments

An estimator is a formula for approximating an unknown population parameter from sample data. Sometimes, we know the form of the population distribution but not the values of its parameters, so we use sample data to estimate them.

The method of moments matches the model's theoretical moments to the sample's own — one equation per unknown parameter — then solves for whatever makes them agree.

$$E[X^k] = \frac{1}{n}\sum_{i=1}^{n} X_i^k, \quad k = 1, 2, \dots$$

A normal distribution with one unknown, its mean, is the simplest case. The model's mean is set equal to the data's mean:

That means the estimator is just the sample mean:

$$\hat{\textcolor{#0b7285}{\mu}} = \bar X$$

A more interesting case is a uniform distribution with one unknown parameter, its upper endpoint. Its mean sits halfway between the two endpoints, so it only reflects half the unknown endpoint's value.

That means the estimator is twice the sample mean:

$$\hat{\textcolor{#0b7285}{\theta}} = 2\bar X$$

If a model had two unknowns instead of one, both the first and second moments would be needed to solve for them.

Maximum Likelihood Estimators

Maximum likelihood estimation picks the parameter value that makes the observed data most probable.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ L(\theta) = \textcolor{#7B4B8C}{\arg\max_{\theta}} \prod_{i=1}^{n} f(x_i; \theta)$$

Products are awkward to differentiate, so in practice the log-likelihood is maximized instead — log is increasing, so it has the same maximizer, with much easier calculus.

$$\hat{\textcolor{#0b7285}{\theta}}_{\text{MLE}} = \textcolor{#7B4B8C}{\arg\max_{\theta}}\ \ell(\theta), \quad \ell(\theta) = \sum_{i=1}^{n} \log f(x_i;\theta)$$

For the normal distribution, the likelihood is maximized when μ̂ is equal to the sample mean too — the same estimator either way:

For the uniform distribution, the likelihood is instead maximized when θ̂ is equal to the largest value actually observed — the sample maximum, not twice the mean:

If there were multiple unknown parameters instead of one, the likelihood would be maximized jointly over all of them at once, not one at a time.

Bayesian Inference

MLE answers "what explains the data best," treating θ as fixed but unknown. Bayesian inference asks instead how this data should update what was already believed about θ. Here θ itself is treated as random, with its own distribution.

$$\pi(\textcolor{#0b7285}{\theta} \mid x) \textcolor{#7B4B8C}{\propto} f(x \mid \textcolor{#0b7285}{\theta})\, \pi(\textcolor{#0b7285}{\theta})$$

π(θ) is the prior — belief about θ before seeing data; f(x∣θ) is the likelihood — how probable the data is for each θ; π(θ∣x) is the posterior — updated belief after seeing it. The ∝ drops a constant that doesn't depend on θ, so it only rescales the curve, not its shape.

A normal prior μ ~ N(μ₀, τ²) on a normal mean gives a normal posterior. Its center is a weighted average of the prior's center and the sample mean:

$$\hat{\textcolor{#0b7285}{\mu}}_{\text{Bayes}} = w\bar X + (1-w)\mu_0, \quad w = \frac{n/\sigma^2}{n/\sigma^2 + 1/\tau^2}$$

As n grows, w → 1 and the estimate approaches the MLE — the prior matters most when data is scarce.

Bias and Mean Squared Error

An unbiased estimator gets the right answer on average, even though any single sample can still land off target.

$$\text{Bias}(\hat{\textcolor{#0b7285}{\theta}}) = E[\hat{\textcolor{#0b7285}{\theta}}] - \textcolor{#0b7285}{\theta}$$

Mean squared error folds bias and variance into one number, so a biased estimator can still win on MSE as long as its variance drops enough to compensate.

$$\text{MSE}(\hat{\textcolor{#0b7285}{\theta}}) = E[(\hat{\textcolor{#0b7285}{\theta}}-\textcolor{#0b7285}{\theta})^2] = \text{Var}(\hat{\textcolor{#0b7285}{\theta}}) + \text{Bias}(\hat{\textcolor{#0b7285}{\theta}})^2$$

With the normal example's data and a hypothetical true μ = 4.2: the MLE X̄ is unbiased but has higher variance (MSE ≈ 0.072), while the biased Bayesian posterior mean has lower variance and wins on MSE (≈ 0.030).

Pivotal Quantities

A recurring problem: a statistic's distribution usually depends on the very parameter being estimated, which seems circular to work with. A pivotal quantity breaks that circularity — built from the data and the parameter together, yet its own distribution doesn't depend on the parameter's actual value.

$$\frac{\bar{X} - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{for every value of } \textcolor{#0b7285}{\mu}$$

Because that distribution is known exactly regardless of the true μ, it can be inverted directly into a confidence interval.

Confidence Intervals

Inverting a pivotal quantity asks which parameter values would make the observed pivot land in its typical range — that range of values is the confidence interval.

$$P\!\left(-t^*_{n-1} \le \frac{\bar X - \textcolor{#0b7285}{\mu}}{S/\sqrt{n}} \le t^*_{n-1}\right) = 1-\textcolor{#c92a2a}{\alpha} \quad\Longrightarrow\quad \textcolor{#0b7285}{\mu} \in \bar X \pm t^*_{n-1}\frac{S}{\sqrt{n}}$$

"95% confidence" describes the procedure, not this one interval: 95% of intervals built this way would contain the true μ. A specific computed interval either does or doesn't — there's no probability left to assign to it.

This coverage is exact only when the data is actually normal. Otherwise a near-pivot — approximately pivotal via a large-sample approximation — serves the same role, with coverage that's only approximate.

Hypothesis Testing

A hypothesis test rejects the null hypothesis when the observed data would be too unlikely if the null were actually true.

$$\textcolor{#7B4B8C}{\text{reject } H_0} \textcolor{#7B4B8C}{\iff} \text{test statistic} \textcolor{#7B4B8C}{\in} \text{rejection region}$$

The rejection region is sized so the test wrongly rejects a true H₀ only a small fraction of the time: below, the shaded tail holds α = 0.05, cut off at z* = 1.645. The observed statistic z = 2.1 falls past z*, so H₀ is rejected.

$$P(\textcolor{#7B4B8C}{\text{reject } H_0} \mid H_0 \text{ true}) = \textcolor{#c92a2a}{\alpha}$$

Equivalently: the p-value is the probability of a test statistic at least as extreme as the one observed, assuming H₀ is true. Reject when p < α — the same decision, expressed as a probability rather than a region.

A test can fail in two ways: rejecting a true H₀ (Type I error), or failing to reject a false one (Type II error). Size is the Type I rate, α; power against a given alternative is one minus the Type II rate.

$$\textcolor{#c92a2a}{\alpha} = P(\text{reject } H_0 \mid H_0) \qquad 1-\textcolor{#0b7285}{\beta} = P(\text{reject } H_0 \mid H_1)$$

Below, the same rejection region is checked against both the null N(0,1) and an alternative N(δ,1), δ = 2.5. The red tail is still α; the teal tail is the power, about 0.80.

Power grows with a larger δ, a larger n, or a larger α — the last trading a higher Type I rate for a lower Type II rate.

Student's t-tests

When the data is approximately normal and the population variance is unknown, estimating that variance from the sample turns a z-statistic into a t-statistic.

$$T = \frac{\bar X - \textcolor{#0b7285}{\mu_0}}{S/\sqrt{n}} \textcolor{#7B4B8C}{\sim} t_{n-1} \quad \text{under } H_0: \mu = \textcolor{#0b7285}{\mu_0}$$

The same form covers three cases: the one-sample test checks a mean against μ₀ (above); the paired test reduces differences Dᵢ = Xᵢ − Yᵢ to a one-sample test on D̄; the two-sample test compares X̄ − Ȳ directly.

$$T = \frac{\bar X - \bar Y}{S_p\sqrt{\tfrac{1}{n_1}+\tfrac{1}{n_2}}} \textcolor{#7B4B8C}{\sim} t_{n_1+n_2-2} \quad \text{(pooled, assumes equal variances)}$$

Likelihood Ratio Test

Another way to test a restriction: compare the best fit under the restriction against the best fit without it. If forcing the restriction barely hurts the fit, it looks plausible.

$$\Lambda = \frac{\sup_{\theta \in \Theta_0} L(\theta)}{\sup_{\theta \in \Theta} L(\theta)}$$

Θ₀ ⊂ Θ is the restricted space under H₀, so Λ ∈ (0, 1] — near 1 means the restriction barely hurt the fit, near 0 means it hurt a lot.

$$-2\log \Lambda \ \xrightarrow{d}\ \chi^2_{k}, \quad k = \dim(\Theta) - \dim(\Theta_0)$$

k is the number of parameters the restriction pins down. Reject H₀ when −2log Λ is too large to plausibly come from that χ² distribution.

Regression Models

A different question from estimation so far: not the best value of a single parameter, but how one variable moves with another. Regression treats the response as a trend plus random noise, not an exact function of the predictor.

$$Y_i = \textcolor{#0b7285}{\beta_0} + \textcolor{#0b7285}{\beta_1} x_i + \varepsilon_i, \quad \varepsilon_i \textcolor{#7B4B8C}{\sim} N(0, \sigma^2)$$

Yᵢ is the response, xᵢ the predictor; β₀, β₁ are the intercept and slope to estimate; εᵢ is leftover randomness, assumed normal with constant variance σ².

Fitting means choosing the coefficients that make the residuals — the leftover noise once the line is drawn — as small as possible.

$$(\hat{\textcolor{#0b7285}{\beta_0}}, \hat{\textcolor{#0b7285}{\beta_1}}) = \textcolor{#7B4B8C}{\arg\min_{\beta_0,\beta_1}} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_i)^2$$

Regression Diagnostics

Fitting always produces some line — it doesn't guarantee a good one. Residual plots check the model's assumptions after the fact, since the true errors are never observed, only their estimates.

$$e_i = y_i - \hat y_i = y_i - (\hat{\textcolor{#0b7285}{\beta_0}} + \hat{\textcolor{#0b7285}{\beta_1}} x_i)$$

Residuals plotted against fitted values should show patternless, constant-width scatter around zero. A pattern — like the fan shape below, where spread grows with the fitted value — signals heteroscedasticity.

A separate summary number, R², reports the proportion of the total variance in y explained by the fitted line rather than left over in the residuals.

$$R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}$$
